=====================================
  نيو دنت - نظام المحاسبة
  نسخة الكمبيوتر
=====================================

طريقة التشغيل على ويندوز:
1) ثبّت Python من:
   https://www.python.org/downloads/
   (فعّل ✓ Add Python to PATH أثناء التثبيت)

2) اضغط مرتين على الملف:
   تشغيل البرنامج.bat

3) أول مرة قد يطلب تثبيت مكتبة، استنى قليلاً.

بيانات الدخول:
المستخدم: admin
كلمة المرور: admin123

=====================================
تحويله لملف exe (اختياري):
1) ثبّت: pip install pywebview pyinstaller
2) من نفس المجلد نفّذ:
   pyinstaller --noconsole --onefile --name "نيو دنت" app.py
3) هتلاقي الملف في مجلد dist
